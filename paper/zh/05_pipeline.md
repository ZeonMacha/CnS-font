# 5. 方法：推理管线、结构门控与矢量化

## 5.1 端到端推理管线

每个目标字符的完整推理管线经历五个阶段：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 阶段 1：输入构造                                                         │
│   - 提取 SC 参考轮廓（Noto Sans CJK，zh-Hans，wght=None）               │
│   - 构造 4 通道脱皮张量（SDF、skel SDF、cos2θ、sin2θ）                    │
│   - 施加推理期抖动：(dw, r_u) 取自重试调度                                │
├──────────────────────────────────────────────────────────────────────────┤
│ 阶段 2：神经 SDF 预测                                                    │
│   - GlobalGlyphTransformer 前向传播 → (pred_sdf, flow_px)                │
│   - CUDA 上 BF16 混合精度，CPU 回退 FP32                                 │
├──────────────────────────────────────────────────────────────────────────┤
│ 阶段 3：SDF → 轮廓矢量化                                                 │
│   - 3× 上采样 SDF（832×832）以获得亚像素轮廓分辨率                        │
│   - 移动轮廓线（marching squares）→ 原始多边形轮廓                       │
│   - 转换为三次 Bézier 段（CFF 指令）                                     │
├──────────────────────────────────────────────────────────────────────────┤
│ 阶段 4：轮廓后处理                                                       │
│   - Taubin 弧长平滑（保端点）                                            │
│   - 曲率掩码直线段吸附（no_snap_mask）                                   │
│   - Hausdorff 保护性回退（max_hausdorff=4.5 UPEM）                       │
│   - 孤岛清理（< 400 UPEM² 碎片）  [v4.5：仍缺失]                         │
├──────────────────────────────────────────────────────────────────────────┤
│ 阶段 5：结构门控验证                                                     │
│   - Chamfer 距离检查                                                     │
│   - p95 分位偏移检查                                                     │
│   - 差异区域覆盖/残留检查                                                │
│   - 拓扑不变量（孔洞、端点、交点）                                       │
│   - PASS → 接受进输出字体                                                │
│   - FAIL → 以抖动 (dw, r_u) 重试 3 次                                   │
│   - 3 次全 FAIL → BlockedToReview（隔离，不进输出字体）                   │
└──────────────────────────────────────────────────────────────────────────┘
```

## 5.2 重试调度

当结构门控拒绝某个候选时，合成器以**抖动后的输入参数**重试，以探索初始预测的邻域：

| 尝试 | $\delta_w$（字重偏移） | $r_u$（半宽，UPEM） |
|:---:|:---:|:---:|
| 0 | 0.00 | 40.0 |
| 1 | −0.04 | 43.0 |
| 2 | +0.05 | 37.0 |

负的 $\delta_w$（尝试 1）使输入 SDF"变细"，鼓励网络预测略粗的笔画。正的 $\delta_w$（尝试 2）反之。$r_u$ 的变化调整骨架半宽，间接控制感知笔重。

**v4.4 统计**：5,421 个总候选中，5,043 个（93.03%）至少在一次尝试中通过。剩余 378 个（6.97%）三次全部失败，被路由至 `BlockedToReview`。

## 5.3 SDF 到轮廓的矢量化

预测 SDF 经以下步骤转换为 OpenType CFF 三次 Bézier 轮廓：

1. **3× 上采样**：256×256 SDF 上采样到 768×768（有效分辨率：1192 UPEM / 768 ≈ 1.55 UPEM/px），以获得亚像素轮廓分辨率。
2. **移动轮廓线（Marching Squares）**：零等值线（$\phi = 0$）被提取为一组多边形轮廓，每条轮廓是一个顶点闭环。
3. **Bézier 拟合**：每条多边形轮廓用最小二乘法拟合为三次 Bézier，最大偏差 $1.8$ UPEM。拟合器（`sdf_to_cff_commands`）产出 `DrawCmd` 对象（move-to、line-to、cubic-to、close），与 CFF 表兼容。
4. **孔洞检测**：轮廓按奇偶规则分类为外边界或孔洞。孔洞数是门控不变量之一。

## 5.4 轮廓后处理

### 5.4.1 Taubin 弧长平滑

在直线段吸附之前，每条轮廓经过 **Taubin 低通平滑**（5 迭代，λ=0.5，μ=−0.53），在保持整体形状的同时降低高频噪声。端点固定以防止轮廓闭合漂移。

### 5.4.2 曲率掩码直线段吸附

`optimize_synthesized_contours_v3` 函数识别拟合 Bézier 轮廓中的**直段**，并将其吸附为精确直线（移除 Bézier 控制点，以 `line-to` 指令替代 `curve-to`）。

**禁吸附掩码（no-snap mask）**：由参考 SC 轮廓的曲率计算掩码。参考曲率处于 [6°, 42°] 区间（即真实弯曲段）的像素被膨胀 28 UPEM 并标记为**禁吸附**——拟合器不得把这些段强制拉直。

**直线段判定**：Bézier 段可被吸附当且仅当：
- 长度 $L \geq 52$ UPEM
- 相对弦的最大垂直偏差 $\leq 4.5$ UPEM
- 不在禁吸附掩码内

### 5.4.3 Hausdorff 保护性回退

吸附之后，每条被修改的轮廓通过**双向 Hausdorff 距离**与原始拟合轮廓比较。若 $d_H > 4.5$ UPEM 或相对面积变化 $> 1.8\%$，则**整条轮廓回退**到无约束 Bézier 拟合。

> **已知局限**：4.5 UPEM 的 Hausdorff 阈值**小于 256 分辨率下的一个像素**（1 px = 4.656 UPEM）。这意味着轮廓上任意一点的单像素扰动都会触发整条回退。结果是 **98.13% 的回退率**（v4.4 中 27,413 条轮廓有 26,942 条回退），摧毁了直线段吸附的收益，并推高了 `on_curve_nodes` 计数。这也是 v4.4 中 `zero_mid` 指标（直笔杆中部无 Bézier 控制点的字形占比）仅为 22.08%（v3 为 67.99%）的主要原因。
>
> **v4.5 修复**：按段（而非整条轮廓）做 Hausdorff 验证，阈值提高到 5.5–6.0 UPEM。

## 5.5 结构门控（StructuralGateV3）

结构门控是一个**基于规则的几何校验器**，在候选字形进入输出字体前对其做多准则检查。所有检查必须同时通过。

### 5.5.1 检查 1：Chamfer 距离

$$d_{\text{chamfer}} = \max\left(\max_{\mathbf{p} \in C_{\text{cand}}} \min_{\mathbf{q} \in C_{\text{ref}}} |\mathbf{p} - \mathbf{q}|,\ \max_{\mathbf{q} \in C_{\text{ref}}} \min_{\mathbf{p} \in C_{\text{cand}}} |\mathbf{q} - \mathbf{p}|\right)$$

候选与 SC 参考的 Chamfer 距离必须 $\leq 28.0$ UPEM（Missing 字形放宽至 $\leq 30.0$）。该检查限定轮廓最大偏差。

### 5.5.2 检查 2：p95 分位偏移

候选与参考轮廓逐点距离的 **p95 分位数**必须满足：
$$p_{95} \leq \begin{cases} 92.0 & \text{若 } d_{\text{chamfer}} \leq 28.0 \text{ 且 } \text{miss}_{\text{sc}} \leq 0.15 \text{ 且 } \text{miss}_{\text{cand}} \leq 0.15 \\ 72.3 & \text{否则} \end{cases}$$

> **已知局限（台阶悬崖）**：阈值在 $d_{\text{chamfer}} = 28.0$ UPEM 处**不连续**。Chamfer = 28.02（仅超出 0.02 UPEM）的字形会从 92.0 上限跌至 72.3，可能误杀。在 v4.4 中，`孖`（Chamfer = 29.49）即受此悬崖影响。**v4.5 修复**：平滑过渡或按部首豁免。

### 5.5.3 检查 3：差异区域覆盖

对 SC-Variant 字形，门控验证**预期替换区域**确实被修改，而非目标区域保持完整：

- $\text{cov}_{\text{dsc}} \geq 0.62$：SC 差异区（日、简不同的像素）中至少 62% 被候选的修改覆盖
- $\text{res}_{\text{djp}} \leq 0.35$：JP 差异区最多 35% 残留未修改

这防止"被动通过"——候选与输入基本相同（实际未发生部首替换）。

### 5.5.4 检查 4：拓扑不变量

- **孔洞数**：$|n_{\text{holes}}^{\text{cand}} - n_{\text{holes}}^{\text{ref}}| \leq 1$
- **端点数**：$|n_{\text{endpoints}}^{\text{cand}} - n_{\text{endpoints}}^{\text{ref}}| \leq 2$
- **交点数**：$|n_{\text{junctions}}^{\text{cand}} - n_{\text{junctions}}^{\text{ref}}| \leq 2$

### 5.5.5 检查 5：条带最大 Chamfer

任意**垂直条带**（宽 100 UPEM）内的最大 Chamfer 距离必须 $\leq 48.8$ UPEM。该检查捕捉全局 Chamfer 可能平均掉的局部极端偏差。

## 5.6 输出封装

通过的字形被封装进两个独立的 OpenType CFF 字体：

| 文件 | 内容 | 字数 |
|:---|:---|:---:|
| `CnS-SkipPro-B-v44-Missing.otf` | 仅缺失字形 | 4,091 |
| `CnS-SkipPro-B-v44-SCVariants.otf` | 仅 SC 变体重绘 | 952 |
| `CnS-SkipPro-B-v44-Full.otf` | 合并：基础 + Missing + SCVariants | 8,095 |

**硬性不变量**（构建时断言）：
1. `Missing ∩ SCVariants = ∅`（码位集不相交）
2. `Missing ∩ Base = ∅`（不覆盖原始字形）
3. `SCVariants ⊆ Base`（变体只替换已有码位）
4. `HARD_KEEP_12` 码位与原始字体逐点精确一致

被拦截的字形隔离在 `manual_review/v44_needs_review.otf`，并附带逐字形诊断 JSON（`v44_needs_review.json`）。
